# Automotive Sales & Service Analytics

This is a data analytics project based on automotive sales and service data. 
The project uses SQL Server for data analysis and Power BI for creating dashboards.

## About the Project

The main aim of this project is to understand the available automotive data and find useful information from it.

The project looks at:

- Car sales and prices
- Different brands and models
- Fuel types
- Sales by year
- Transmission types
- Owners data
- Insurance data
- Service history

The data is stored in CSV files and analyzed using SQL queries. The results are then used in Power BI to create visual reports.

## Tools Used

- SQL Server
- SQL Server Management Studio (SSMS)
- Power BI
- CSV / Excel
- GitHub

## Power BI Dashboard

The dashboard contains the following analysis:

The main SQL file used in this project is:

The SQL queries are used for different types of analysis, such as:

- Sales analysis
- Brand and model analysis
- Fuel type analysis
- Price analysis
- Mileage analysis
- Performance categorization
- Basic aggregations

## How to Run

### SQL

1. Import the CSV files into SQL Server.
2. Open `car_sales_analytics.sql` in SSMS.
3. Select the required database.
4. Run the SQL queries.

### Power BI

1. Open `Automotive_Sales_Service_Analytics.pbix` in Power BI Desktop.
2. If Power BI asks for the data source, select/update the local data source.
3. Refresh the data if required.
4. Open the report pages to view the dashboard.
